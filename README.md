# J&E Studio Homebrew tap

Install the standalone je client on an Apple Silicon Mac:

```sh
brew install jestatsio/tap/je
je setup
```

Python is bundled. Setup detects installed Codex and Claude Code CLIs and asks before adding their native Studio plugins. Install those clients separately.

[Documentation](https://jestatsio.github.io/je/) · [Releases](https://github.com/jestatsio/je/releases)

Studio service access requires an operator-provided endpoint, permitted model, and personal key.
